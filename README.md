# Personal Google Workspace CLI information

Public homepage and privacy policy for Seongho's personal `gmail-automation` OAuth app, used with gogcli for Gmail and Google Calendar.

- Homepage: https://psh4607.github.io/policy/gcp/
- Privacy policy: https://psh4607.github.io/policy/gcp/privacy.html
- Hosting: GitHub Pages, static HTML and CSS, no build dependencies.

This repository contains only public explanatory pages. Do not add OAuth credentials, tokens, account exports, or private messages.

The Google OAuth pages live under `policy/gcp/`; they do not replace the root homepage.
