## 1. 기기에서 처리하는 정보와 목적

앱은 회원가입이나 로그인을 요구하지 않습니다. 사진 재생을 위해 다음 정보를 기기에서 처리합니다.

| 정보 | 처리 목적과 보관 위치 |
| --- | --- |
| 사용자가 시스템 사진 선택기에서 선택한 사진 | 오프라인 재생을 위해 앱 전용 내부 저장소에 복사합니다. |
| 사용자가 접근을 허용한 기기 사진과 앨범 정보 | 앨범 목록과 사진 수를 표시하고, 선택한 앨범의 사진을 재생합니다. 앨범 방식에서는 원본을 참조하며 별도 사진 복사본을 만들지 않습니다. |
| 사진 경로 또는 URI, 선택한 앨범의 식별자와 이름 | 선택한 사진 목록을 복원하고 재생합니다. 앱 전용 설정 저장소에 보관합니다. |
| 표시 시간, 순차·무작위 설정, 재생 순서와 현재 위치, 안내 표시 여부 | 앱을 다시 실행해도 설정과 재생 상태를 유지합니다. 앱 전용 설정 저장소에 보관합니다. |

선택기로 가져오는 사진은 원본 파일 내용을 복사하므로, 파일에 촬영 시각이나 위치 등의 메타데이터가 포함되어 있다면 복사본에도 남을 수 있습니다. 앱은 이를 별도로 추출해 위치를 추적하거나 분석하지 않습니다. 기기 앨범의 사진 정렬에는 미디어 저장소의 촬영일 정보를 사용합니다.

## 2. 사진 접근 권한

‘사진 직접 선택’과 ‘Google Photos에서 선택’은 Android 시스템 사진 선택기를 사용합니다. 앱은 사용자가 선택한 항목을 가져옵니다.

‘휴대폰 앨범’을 선택하면 Android 버전에 따라 사진 또는 저장소 읽기 권한을 요청합니다. Android 14 이상에서 일부 사진만 허용한 경우에는 허용된 사진 범위에서 앨범을 표시하고 재생합니다. 선택한 기기 앨범의 목록은 앱으로 돌아오거나 액자를 시작할 때 갱신합니다.

기기 설정에서 사진 접근 권한을 변경하거나 철회할 수 있습니다. 권한을 허용하지 않더라도 시스템 사진 선택기로 사진을 가져올 수 있습니다. 권한을 철회하면 앨범의 원본 사진을 읽지 못할 수 있지만, 이미 앱 내부에 복사한 사진은 자동으로 삭제되지 않습니다.

## 3. 서버 전송과 제3자 서비스

현재 앱은 개발자 서버로 사진이나 재생 설정을 전송하지 않습니다. 광고, 사용자 행동 분석, 별도 오류 수집 SDK를 사용하지 않으며, 앱에 인터넷 접근 권한을 선언하지 않습니다. 앱이 사진을 외부에 공유하거나 판매하는 기능도 없습니다.

Google Photos 등 클라우드 사진의 선택과 다운로드는 기기에 연결된 시스템 사진 선택기 및 사진 제공자의 기능에 따라 이루어집니다. 앱이 Google 계정의 비밀번호나 인증 토큰을 받거나, Google Photos 앨범을 직접 동기화하지는 않습니다. 제공자의 서비스 이용에는 해당 제공자의 개인정보 처리방침이 적용됩니다.

Google Play의 앱 배포·구매·기기 진단 등 Google 자체 서비스에서 처리하는 정보에는 [Google 개인정보처리방침](https://policies.google.com/privacy)이 적용됩니다. 이러한 서비스의 처리는 앱이 직접 수행하는 처리와 구분됩니다.

이 개인정보처리방침 웹페이지는 GitHub Pages에서 제공합니다. 자체 광고나 분석 스크립트를 사용하지 않습니다. 페이지 방문에 따른 IP 주소 등 호스팅 정보는 [GitHub 개인정보처리방침](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)에 따라 처리될 수 있으며, 앱 내부 사진이 이 웹페이지로 전송되는 것은 아닙니다.

## 4. 보관 기간과 삭제 방법

사진 복사본과 설정은 앱의 기능을 제공하는 동안 기기에 보관합니다. 별도의 기간 경과에 따른 자동 삭제 기능은 없습니다.

새 사진 목록이나 다른 사진 소스로 성공적으로 변경하면 앱은 이전에 가져온 사진 복사본 중 더 이상 사용하지 않는 항목을 정리합니다. 저장 실패, 비정상 종료 또는 파일 삭제 실패가 발생하면 사용하지 않는 복사본이 남을 수 있습니다.

앱에 저장된 사진 복사본과 설정을 모두 삭제하려면 Android 설정에서 이 앱의 **저장공간 → 데이터 삭제**를 사용하거나 앱을 삭제합니다. 메뉴 이름은 기기에 따라 다를 수 있습니다. **캐시 삭제만으로는 가져온 사진과 설정이 모두 삭제되지 않습니다.** 현재 앱 안에는 전체 삭제 버튼이 없습니다.

앱의 데이터 삭제나 앱 삭제는 휴대폰 갤러리 또는 클라우드에 있는 원본 사진을 삭제하지 않습니다. 원본 사진을 갤러리나 클라우드에서 삭제하더라도 이미 가져온 앱 내부 복사본은 별도로 삭제해야 합니다.

개발자는 기기에 저장된 사진과 설정에 원격으로 접근하거나 이를 대신 삭제할 수 없습니다. 앱 계정을 만들지 않으므로 별도의 회원 탈퇴 절차는 없습니다.
