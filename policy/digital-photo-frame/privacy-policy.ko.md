## 기기 갤러리 앨범 연결 (개발 중인 기능)

다음 설명은 ‘갤러리 앨범 연결하기’ 기능이 포함된 빌드에만 적용됩니다. 기존 설치본의 수동 가져오기와 다르며, 이 방침의 게시가 기능 출시를 의미하지는 않습니다.

연결 대상은 앱이 설치된 같은 기기의 폴더 기반 앨범입니다. 갤러리 앱 자체의 인물·즐겨찾기 분류나 다른 기기의 앨범은 대상이 아닙니다. 앱은 연결한 앨범의 저장 볼륨·앨범(버킷) 식별자, 이름·경로, 사진의 원본 content URI와 연결·재생 상태를 앱 내부 저장소에 보관합니다. 연결 사진은 원본을 읽으며 내부 사진 복사본을 만들지 않습니다.

전체 사진 읽기 권한이 있어야 연결할 수 있습니다. 일부 사진만 허용하거나 거절하면 연결을 완료하지 않습니다. 시스템에서 재요청할 수 있는 경우 사용자의 조작으로 다시 권한을 요청하고, 재요청할 수 없으면 기기 설정으로 안내합니다. 연결 후 권한이 철회되거나 일부 접근으로 바뀌면 연결과 기존 목록을 보존하고 연결 사진 재생을 일시 중지합니다. 전체 권한을 복구한 뒤 다시 조회합니다.

앱을 열거나 액자를 시작할 때와 재생 중 감지한 기기 사진 변경 시 연결 폴더의 목록을 갱신합니다. 사진 추가·삭제를 액자 목록에 반영하는 단방향 연결이며 갤러리 원본을 수정하거나 삭제하지 않습니다. 권한 부족이나 조회 오류만으로 연결과 기존 목록을 삭제하지 않습니다. 연결 해제 또는 연결 앨범 삭제는 앱의 연결 정보·사진 목록·재생 상태만 제거합니다.

수동 앨범으로 가져온 내부 복사본에는 기존 보관·삭제 방식이 적용됩니다. Google Photos Picker 직접 가져오기 방식도 변경하지 않습니다. Google Photos Ambient API는 파트너 승인 대기 중으로 제공하지 않으며, 승인 대기 중 또는 준비 중 화면에서 해당 기능의 접근 권한을 요청하거나 데이터를 가져오지 않습니다.

## 2. 사진 접근 권한

사진 추가 화면에서 휴대폰 갤러리 또는 Google Photos를 선택할 수 있습니다. 휴대폰 갤러리는 기기의 미디어 저장소에서 앨범과 사진을 읽고 사용자가 선택한 사진만 앱 내부 저장소로 복사합니다. Android 12L 이하에서는 저장소 읽기 권한, Android 13 이상에서는 사진 읽기 권한을 요청합니다. Android 14 이상에서 일부 사진만 허용한 경우에는 허용된 사진 범위에서 목록을 표시합니다. 거부한 권한은 기기 설정에서 변경할 수 있습니다.

Android 시스템 사진 선택기를 사용하는 경로에서는 사용자가 선택한 항목만 접근하며 전체 사진 접근 권한이 필요하지 않습니다. 이전의 사진 선택기 전용 화면과 ‘Google Photos에서 선택’이라는 이름으로 시스템 선택기를 열던 화면은 이 방식에 해당합니다. 별도 Google Photos 연결 화면이 있는 새 기능과는 다릅니다. 새 사진 소스 화면과 Google Photos 직접 가져오기는 개발 중이며, 이 방침의 게시가 앱 업데이트 배포나 Google 인증 심사 완료를 의미하지는 않습니다.

Google Photos 직접 가져오기는 Google이 제공하는 계정 인증과 선택 화면을 사용합니다. 앱이 요청하는 Google 접근 범위는 사용자가 선택한 미디어를 읽기 위한 `photospicker.mediaitems.readonly`입니다. 전체 Google Photos 보관함이나 앨범을 읽는 권한, 이메일·프로필 조회 권한, 오프라인 접근용 갱신 토큰은 요청하지 않습니다. Google 계정 비밀번호를 앱에 입력하거나 개발자에게 제공하지 않습니다.

기기 설정에서 사진 접근 권한을 변경하거나 철회할 수 있습니다. Google 접근 권한은 [Google 계정의 연결 관리](https://myaccount.google.com/connections)에서 해제할 수 있습니다. 권한을 철회하거나 원본을 삭제하면 기존 원본 참조 사진을 읽지 못할 수 있지만, 이미 앱 내부에 복사한 사진은 자동으로 삭제되지 않습니다. 수동 앨범으로 사진을 가져온 뒤에는 원본 앨범의 추가·삭제를 자동으로 반영하지 않습니다.

이전 버전의 사진과 재생 상태는 업데이트 시 앱 앨범으로 이전합니다. 이전 버전에서 기기 앨범의 원본 URI로 저장했던 사진은 데이터 손실을 피하기 위해 원본 참조를 유지할 수 있습니다. 이러한 사진은 자동 동기화하지 않으며, 원본 삭제나 권한 변경으로 재생하지 못할 수 있습니다. 새로 가져오는 사진에는 내부 복사 방식을 적용합니다.

## 3. 서버 전송과 제3자 서비스

앱은 개발자 서버로 사진이나 재생 설정을 전송하지 않습니다. 광고, 사용자 행동 분석, 별도 오류 수집 SDK를 사용하지 않습니다. Google Photos 직접 가져오기를 위해 인터넷 접근 권한을 선언하며, 가져온 사진의 재생은 오프라인에서 가능합니다.

Google Photos를 선택한 경우 Google Play 서비스의 인증 기능으로 접근 토큰을 받고, HTTPS로 Google Photos Picker API에 선택 세션을 생성하고 선택 완료 여부와 선택 항목을 조회합니다. API 요청은 `photospicker.googleapis.com`으로, 사진 다운로드는 Google의 `googleusercontent.com` 하위 도메인으로 전송됩니다. 토큰은 해당 요청의 인증에 사용하며 사진은 Google에서 기기로 다운로드합니다. 계정 인증과 사진 선택 과정에는 Google 서비스와 브라우저가 관여하며, 이 과정의 처리에는 [Google 개인정보처리방침](https://policies.google.com/privacy)이 적용됩니다.

앱은 접근 토큰, 선택 세션 정보와 임시 다운로드 주소를 작업 중 메모리에만 보관하며 파일이나 데이터베이스에 저장하지 않습니다. Google Play 서비스와 브라우저가 관리하는 계정·인증 상태는 각 서비스의 동작과 설정을 따릅니다. 중복 가져오기를 확인하기 위한 Google Photos 미디어 식별자는 사진 목록과 함께 앱 내부 데이터베이스에 보관합니다. 앱은 별도의 갱신 토큰을 받거나 보관하지 않습니다.

Google Photos에서 받은 정보는 사용자가 요청한 사진 가져오기, 앱 앨범 관리와 액자 재생에 사용합니다. 사진이나 관련 정보를 판매하거나 광고·분석·AI 학습에 사용하지 않습니다. Google API에서 받은 정보의 이용은 제한적 사용(Limited Use) 요건을 포함한 [Google API 서비스 사용자 데이터 정책](https://developers.google.com/terms/api-services-user-data-policy)과 [Google Photos API 사용자 데이터 및 개발자 정책](https://developers.google.com/photos/support/api-policy)을 따릅니다.

Google Photos 앨범 자동 동기화와 Ambient API 연동은 현재 제공하지 않습니다. 화면에 준비 중이라고 표시된 항목은 향후 설계 안내이며, 해당 기능의 접근 권한을 요청하거나 데이터를 가져오지 않습니다.

시스템 사진 선택기를 통한 클라우드 사진 선택은 기기에 연결된 사진 제공자의 기능에 따라 이루어지며, 해당 제공자의 개인정보처리방침이 적용됩니다.

Google Play의 앱 배포·구매·기기 진단 등 Google 자체 서비스에서 처리하는 정보에는 [Google 개인정보처리방침](https://policies.google.com/privacy)이 적용됩니다. 이러한 서비스의 처리는 앱이 직접 수행하는 처리와 구분됩니다.

이 개인정보처리방침 웹페이지는 GitHub Pages에서 제공합니다. 자체 광고나 분석 스크립트를 사용하지 않습니다. 페이지 방문에 따른 IP 주소 등 호스팅 정보는 [GitHub 개인정보처리방침](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)에 따라 처리될 수 있으며, 앱 내부 사진이 이 웹페이지로 전송되는 것은 아닙니다.

## 4. 보관 기간과 삭제 방법

사진 복사본, 중복 확인용 원본 식별자와 설정은 앱의 기능을 제공하는 동안 기기에 보관합니다. 별도의 기간 경과에 따른 자동 삭제 기능은 없습니다.

Google Photos 가져오기를 완료하거나 취소하거나 오류가 발생하면 앱은 Google의 선택 세션 삭제를 시도합니다. 네트워크 연결 실패나 앱 프로세스 종료 등으로 삭제 요청이 완료되지 않을 수 있으며, 남은 세션은 Google이 정한 만료 정책을 따릅니다. 선택 세션 삭제나 Google 접근 권한 해제는 이미 가져온 내부 사진 복사본을 삭제하지 않습니다.

기존 단일 목록 버전은 사진 목록이나 소스를 성공적으로 교체하면 이전 내부 복사본 중 더 이상 사용하지 않는 항목을 정리합니다.
