연결 대상은 앱이 설치된 같은 기기의 폴더 기반 앨범과 Android 11 이상에서 시스템 미디어 저장소(MediaStore)에 즐겨찾기로 지정된 사진 모음입니다. 즐겨찾기는 시스템에 공유된 지정 정보를 기준으로 같은 기기의 사진을 모으며, 사진이 없어도 연결해 두고 이후 변경을 반영할 수 있습니다. 갤러리 앱이 자체적으로 보관하거나 클라우드에서만 관리하여 시스템에 공유하지 않는 즐겨찾기, 인물 분류, 다른 기기의 앨범은 대상이 아닙니다. 앱은 연결한 앨범의 저장 볼륨·앨범(버킷 또는 즐겨찾기 모음) 식별자, 이름·경로, 사진의 원본 content URI와 연결·재생 상태를 앱 내부 저장소에 보관합니다. 연결 사진은 원본을 읽으며 내부 사진 복사본을 만들지 않습니다.

전체 사진 읽기 권한이 있어야 연결할 수 있습니다. 일부 사진만 허용하거나 거절하면 연결을 완료하지 않습니다. 시스템에서 재요청할 수 있는 경우 사용자의 조작으로 다시 권한을 요청하고, 재요청할 수 없으면 기기 설정으로 안내합니다. 연결 후 권한이 철회되거나 일부 접근으로 바뀌면 연결과 기존 목록을 보존하고 연결 사진 재생을 일시 중지합니다. 전체 권한을 복구한 뒤 다시 조회합니다.

앱을 열거나 액자를 시작할 때와 재생 중 감지한 기기 사진 변경 시 연결한 폴더 또는 시스템 즐겨찾기 모음의 목록을 갱신합니다. 사진 추가·삭제와 시스템 즐겨찾기 지정·해제를 액자 목록에 반영하는 단방향 연결이며 갤러리 원본을 수정하거나 삭제하지 않습니다. 권한 부족이나 조회 오류만으로 연결과 기존 목록을 삭제하지 않습니다. 연결 앨범 삭제는 앱의 연결 정보·사진 목록·재생 상태만 제거합니다.

동영상은 한 편을 끝까지 재생한 뒤 다음 항목으로 이동하며 소리는 기기의 미디어 볼륨을 따릅니다. 순차 재생은 사진 다음 동영상 순서이고 무작위 재생은 사진과 동영상을 함께 섞습니다. 아래 내부 복사본의 보관·삭제·정보 보호 및 개발자 서버로 전송하지 않는다는 설명은 동영상에도 동일하게 적용됩니다. 이 방침의 게시는 해당 기능의 출시를 의미하지 않습니다.

OneDrive·Dropbox 사진·동영상 가져오기와 폴더 연결 (개발 중인 기능)

이 설명은 OneDrive·Dropbox 기능이 포함된 빌드에만 적용되며, 방침 게시는 기능 출시나 서비스의 운영 심사 완료를 의미하지 않습니다. OneDrive는 개인 Microsoft 계정을 지원합니다. 사용자가 제공자를 선택하면 해당 서비스의 로그인·동의 화면을 열며, 앱이나 개발자에게 비밀번호를 제공하지 않습니다. 앱은 Microsoft의 MSAL과 Dropbox의 PKCE 인증을 사용하여 사진·동영상·폴더를 읽고 로그인을 유지하는 권한을 요청합니다. 원본을 업로드·수정·삭제하는 권한은 요청하지 않습니다.

앱에서 만든 수동 앨범에는 사용자가 직접 선택한 사진 또는 동영상만 내부 저장소로 다운로드합니다. 사진 선택과 동영상 선택에는 해당 미디어 종류만 표시합니다. 이후 클라우드 원본의 추가·변경·삭제를 자동 반영하지 않습니다. 폴더 연결은 사용자가 선택한 한 폴더의 바로 아래 사진을 대상으로 하며 하위 폴더나 동영상을 포함하지 않습니다. 앱이 화면에 활성화된 동안 약 60초마다, 또는 사용자가 새로고침할 때 목록과 사진 변경을 확인합니다. 앱이 백그라운드에 있는 동안 계속 동기화한다고 보장하지 않습니다.

연결한 사진은 오프라인 재생을 위해 앱 전용 내부 저장소에 다운로드합니다. 제공자·계정 식별자, 표시 이름, 연결 폴더 식별자·이름·경로, 사진 식별자·변경 버전, 내부 파일 URI와 연결·재생 상태를 기기에 저장합니다. 전체 목록 조회와 필요한 다운로드가 성공한 경우에만 새 목록을 저장합니다. 성공한 동기화에서 원본 삭제를 확인하면 앱의 연결 목록에서도 제거하고 다른 앨범에서 사용하지 않는 내부 복사본을 정리합니다. 로그인 만료·권한 부족·네트워크 또는 다운로드 오류만으로 기존 목록이나 복사본을 지우지 않습니다.

앨범 연결을 해제하면 현재 내부 복사본을 보존한 수동 앨범으로 전환합니다. 제공자 계정의 연결 해제는 앱이 보관한 해당 제공자의 로그인 정보를 제거하지만, 기존 앨범과 사진 복사본을 삭제하지 않습니다. 남아 있는 연결 앨범을 갱신하려면 다시 로그인해야 합니다. 클라우드 원본은 어느 경우에도 수정하거나 삭제하지 않습니다.

Microsoft·Dropbox 로그인 유지에 필요한 토큰은 각 인증 방식에 따라 보호된 기기 내 저장소에 보관합니다. 기기의 앱 데이터 삭제 또는 앱 삭제 시 앱의 토큰과 내부 데이터가 제거됩니다. 브라우저나 제공자 앱이 관리하는 로그인 상태는 해당 서비스의 설정을 따르며, 앱에서 연결을 해제해도 서비스 측 동의를 철회하는 것은 아닙니다. Microsoft 또는 Dropbox 계정의 연결된 앱 관리에서도 접근 권한을 철회할 수 있습니다.

인증·폴더 조회·사진·동영상 다운로드는 HTTPS로 기기와 Microsoft 또는 Dropbox 사이에서 이루어지며 개발자 서버를 거치지 않습니다. Microsoft 로그인과 Microsoft Graph API 및 다운로드 호스트, Dropbox 로그인과 API·콘텐츠 호스트에 인증·조회 요청을 보냅니다. 해당 처리에는 Microsoft 개인정보처리방침과 Dropbox 개인정보처리방침이 각각 적용됩니다. 다운로드한 사진·동영상에는 원본 파일에 포함된 촬영 시각·위치 등의 메타데이터가 남을 수 있습니다. 사진·동영상과 관련 정보를 판매하거나 광고·분석·AI 학습에 사용하지 않습니다.

정보 처리 목적과 보관 위치
