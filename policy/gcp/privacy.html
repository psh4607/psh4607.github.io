개인정보처리방침

gmail-automation · 시행일: 2026년 9월 28일

이 방침은 박성호가 자신의 Google 계정을 gogcli에 연결해 사용하는 개인용 도구에 적용됩니다. 이 웹사이트는 해당 도구의 기능과 데이터 처리 방식을 안내합니다.

1. 접근하는 정보와 이용 목적

  • 계정 정보: 이메일 주소와 Google 계정 식별자를 사용해 연결 계정을 구분합니다.
  • Gmail: 사용자가 요청한 검색·조회·작성·발송·관리를 위해 메시지 본문, 발신·수신 정보, 첨부파일, 라벨, 필터 및 메일 설정에 접근할 수 있습니다.
  • Google Calendar: 사용자가 요청한 일정 관리를 위해 캘린더, 일정 제목·내용·시간·장소·참석자와 관련 설정에 접근할 수 있습니다.
  • OAuth 인증 정보: Google API에 접근하고 승인된 연결을 갱신하는 데 사용합니다. Google 계정 비밀번호를 이 도구에 입력하거나 저장하지 않습니다.

Google 데이터는 사용자가 요청한 메일·일정 기능을 제공하는 데 사용합니다. 앱 운영자는 이를 판매하거나 광고 타기팅 또는 범용 AI 모델 학습을 위한 데이터로 사용하지 않습니다.

2. 처리 위치와 외부 서비스

gogcli는 사용자의 Mac에서 실행되며 Google API와 통신합니다. OAuth 토큰과 클라이언트 보안 비밀번호는 Mac 키체인에 저장합니다. 이 공개 안내 사이트는 OAuth 토큰, 메일 또는 일정을 수집하는 서버나 로그인 양식을 운영하지 않습니다.

사용자가 AI 에이전트에 작업을 맡기면, 해당 작업에 필요한 메일·일정 정보와 도구 실행 결과가 사용자가 선택한 AI 서비스에 전달되고 대화 기록에 포함될 수 있습니다. 해당 서비스의 저장 기간과 처리 방식에는 그 서비스의 약관, 개인정보처리방침 및 사용자의 계정 설정이 적용됩니다. 연결 승인만으로 메일 전체를 이 웹사이트에 업로드하지 않습니다.

이 사이트는 GitHub Pages에서 제공하며 자체 분석 스크립트나 광고 쿠키를 사용하지 않습니다. 사이트 방문에 따른 IP 주소 등의 호스팅 로그는 GitHub 개인정보처리방침에 따라 처리될 수 있습니다.

3. 보관과 삭제

메일과 일정 원본은 Google 계정에 보관됩니다. 로컬에 저장한 첨부파일·내보내기 파일·명령 실행 기록과 AI 서비스의 대화 기록은 각각의 저장 위치와 서비스 설정에 따라 남을 수 있습니다. 사용자는 필요한 작업에만 데이터를 사용하고, 더 이상 필요하지 않은 로컬 파일과 대화 기록을 해당 위치에서 삭제할 수 있습니다.

연결을 종료하려면 Google 계정의 서드 파티 연결에서 이 앱의 접근 권한을 철회하고, gogcli에서 저장된 계정 연결을 삭제하면 됩니다. 권한 철회는 향후 Google API 접근을 차단하며, 이미 별도로 저장한 파일이나 대화 기록은 해당 저장소에서 따로 삭제해야 합니다.

4. Google API 데이터 이용 원칙

gmail-automation의 Google API를 통해 받은 정보의 사용 및 다른 앱으로의 전송은 Limited Use 요건을 포함한 Google API Services User Data Policy를 따릅니다. Google 사용자 데이터는 사용자가 요청한 기능을 제공하는 데 필요한 범위에서 처리합니다.
